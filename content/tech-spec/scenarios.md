# 2. 시나리오

사용자는 받은 문자를 붙여넣거나 통화 녹음을 보내기만 합니다. 5초 안에 "확인하고 있어요"가 오고, 결과 카드는 뒤이어 도착합니다.

## 1. 링크가 있는 문자

> [택배 안내] 배송지 정보가 일치하지 않습니다. 아래에서 주소를 확인해 주세요. https://delivery-check.example

격리 서버가 링크를 열어 보고, 공식 주소와 대조하고, 페이지를 검사합니다. 사용자 기기는 링크에 닿지 않습니다.

| 결과 카드 | 언제 |
| --- | --- |
| ⚠️ 스미싱이 의심돼요 | 페이지가 앱 설치 파일을 띄우는 것처럼, 검증된 위험 신호가 있을 때 |
| 🔗 ○○ 공식 주소와 같아요 | 공식 주소이고 위험 신호를 찾지 못했을 때 |
| 🔎 공식 주소가 아니에요 | 택배사를 내세웠는데 그 택배사의 공식 주소가 아닐 때 |
| 🤔 판단하기 어려워요 | 택배사를 특정할 수 없거나 페이지에 접근하지 못했을 때 |

`자세히 보기`를 누르면 의심 근거, 확인한 범위, 공식 확인 방법을 캐러셀로 보여 줍니다.

## 2. 링크가 없는 사칭 문자

> 엄마 나 폰 고장 나서 이 번호로 연락해. 급하게 상품권 좀 사 줄 수 있어?

가족 주장과 상품권 요구가 함께 있으면 **주의가 필요한 문자예요**가 옵니다. 아래에 두 가지 질문이 붙습니다.

- **이미 하신 게 있나요?** "돈이나 상품권을 보냈어요"를 고르면 112 신고 안내가 옵니다.
- **원래 알던 번호로 통화해 보셨나요?** "본인이 아니래요"를 고르면 결론이 **사칭 문자로 의심돼요**로 바뀝니다.

## 3. 통화 녹음

음성 메시지나 파일(m4a, mp3, wav, webm)로 보냅니다. 받아쓰기 뒤 기관 자기소개와 요구를 읽습니다.
"○○지검 수사관입니다 … 안전계좌로 옮기셔야 합니다"처럼 기관 사칭과 송금 요구가 함께 있으면 **보이스피싱이 의심돼요**가 됩니다.

## 그 밖의 흐름

| 상황 | 동작 |
| --- | --- |
| 결과가 오지 않았다 | 「결과 확인」을 보내면 가장 최근 결과를 다시 보내 줍니다 |
| 분석 중에 또 보냈다 | 새로 분석하지 않고 "앞서 보내 주신 내용을 확인하고 있어요"로 답합니다 |
| 이미 링크를 눌렀거나 돈을 보냈다 | 하단 메뉴 `신고 상담`에서 상황을 고르면 KISA 118, 1394, 112로 이어 줍니다 |
| 링크가 여러 개다 | 링크마다 결과 카드를 보냅니다 |
