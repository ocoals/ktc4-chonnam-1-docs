# 2. 시나리오

사용자는 받은 문자를 붙여넣거나 통화 녹음을 보내기만 합니다. 5초 안에 "확인하고 있어요"가 오고, 결과 카드는 뒤이어 도착합니다.

## 처음 들어왔을 때

> 🛡️ **의심되는 문자·전화, 먼저 확인해요**
> 반가워요, 피싱 확인을 도와주는 화기니예요. 의심스러운 문자나 통화 녹음을 보내주시면 확인 결과와 이유를 알려드려요.

`피싱 확인하기`를 누르면 문자를 복사하는 법과 아이폰, 갤럭시에서 녹음을 보내는 법을 안내합니다. `개인정보 처리 안내`에서는 문자와 녹음을 어디서 처리하는지 알려 줍니다.
하단 메뉴에는 `피싱 확인`, `신고 상담`, `개인정보 처리 안내`가 늘 있습니다.

## 1. 링크가 있는 문자

> [Web발신] 고객님 명의로 결제가 요청되었습니다. 본인이 아니면 아래에서 바로 취소해 주세요. https://pay-cancel.example

격리 서버가 링크를 열어 보고, 문자가 내세운 업체의 공식 주소와 대조하고, 페이지를 검사합니다. 사용자 기기는 링크에 닿지 않습니다.

| 결과 카드 | 언제 |
| --- | --- |
| ⚠️ 스미싱이 의심돼요 | 페이지가 앱 설치 파일을 띄우거나 비밀번호를 묻는 것처럼, 검증된 위험 신호가 있을 때 |
| 🔗 ○○ 공식 주소와 같아요 | 공식 주소이고 위험 신호를 찾지 못했을 때 |
| 🔎 공식 주소가 아니에요 | 알려진 업체를 내세웠는데 그 업체의 공식 주소가 아닐 때 |
| 🔎 주의가 필요한 문자예요 | 판단을 보류할 링크인데 문자에 주의할 말이 있을 때. 계정이 정지됐으니 링크에서 풀라거나, 로또 당첨을 내세워 링크로 끌어들이는 문자 같은 경우 |
| 🤔 판단하기 어려워요 | 어느 업체인지 알 수 없거나 페이지에 접근하지 못했을 때 |
| 🙏 이번에는 확인하지 못했어요 | 그 링크의 분석이 실패했을 때 |

`자세히 보기`를 누르면 캐러셀이 옵니다. 의심 근거(신호마다 한 장), 확인한 범위, 문자 속 링크에 접속하지 말라는 안내와 KISA 상담 버튼, 공식 확인 방법(최대 3장) 순서입니다.
"판단하기 어려워요" 카드에는 `확인한 것`, `확인하지 못한 것`, `문자에 적힌 내용`을 함께 적습니다.
"주의가 필요한 문자예요"는 링크 없는 사칭 문자와 같은 카드를 씁니다. 링크를 누르지 말라는 안내로 시작하고, `주의할 점`, `확인한 것`, `확인하지 못한 것`을 본문에 함께 적습니다. `자세히 보기`와 질문 카드는 붙지 않습니다.

## 2. 링크가 없는 사칭 문자

> 엄마 나 폰 고장 나서 이 번호로 연락해. 급하게 상품권 좀 사 줄 수 있어?

가족 주장과 상품권 요구가 함께 있으면 **주의가 필요한 문자예요**가 옵니다. 멈춰야 할 행동, 확인 방법, 확인한 것과 확인하지 못한 것이 함께 오고, 아래에 두 가지 질문이 붙습니다.

- **이미 하신 게 있나요?** "돈이나 상품권을 보냈어요"를 고르면 112 신고 안내가, "아무것도 안 했어요"를 고르면 KISA 상담 안내가 옵니다.
- **원래 알던 번호로 통화해 보셨나요?** "본인이 아니래요"를 고르면 결론이 **사칭 문자로 의심돼요**로 바뀝니다.

사칭이나 요구하는 말이 없으면 "사칭이나 요구하는 말을 찾지 못했어요"가 옵니다. 링크 없는 문자에는 "스미싱" 대신 "사칭"이라는 말을 씁니다.

## 3. 통화 녹음

음성 메시지나 파일(m4a, mp3, wav, webm)로 보냅니다. 받아쓴 대본에서 기관명, 송금 요구 같은 위험한 말을 찾아내고, 그 말이 실제 대본에 있는지 확인합니다.
"○○지검 수사관입니다 … 안전계좌로 옮기셔야 합니다"처럼 기관명과 송금 요구가 함께 나오면 **보이스피싱이 의심돼요**가 됩니다. 결과는 의심, 주의가 필요한 통화, 판단하기 어려움 가운데 하나입니다.

`자세히 보기`는 의심되는 말, 비슷한 사례, 확인한 범위, 요구에 응하지 말라는 안내와 1394 상담 버튼, 공식 확인 방법 순서로 보여 줍니다. 비슷한 사례 장은 가장 비슷한 예시 통화의 수법(가족, 지인 사칭, 납치 빙자, 통장 모집 등)을 한 줄로 설명합니다.
오디오가 아니거나, 읽을 수 없거나, 25 MB를 넘거나, 알아들을 말이 없으면 그 이유를 알려 주는 카드가 옵니다.

## 이미 링크를 눌렀거나 돈을 보냈을 때

하단 메뉴 `신고 상담`에서 상황을 고르면 맞는 창구로 이어 줍니다.

| 고른 상황 | 이어 주는 곳 |
| --- | --- |
| 문자만 받았어요 | 보내는 법 안내, KISA 상담 |
| 링크를 눌렀어요 | KISA 전화 상담(118), KISA 채팅 상담 |
| 전화만 받았어요 | 녹음 보내는 법, 1394 상담 |
| 통화 중 돈이나 정보를 줬어요 | 112 신고, 1394 상담 |

## 그 밖의 흐름

| 상황 | 동작 |
| --- | --- |
| 결과가 오지 않았다 | 「결과 확인」을 보내면 가장 최근 결과를 다시 보내 줍니다. 아직 분석 중이면 그렇다고 알려 줍니다 |
| 분석 중에 또 보냈다 | 새로 분석하지 않고 "앞서 보내 주신 내용을 확인하고 있어요"로 답합니다 |
| 링크가 여러 개다 | 링크마다 결과 카드를 보냅니다 |
| 문자가 너무 길다(8,192자 초과) | 확인하고 싶은 부분만 다시 보내 달라고 안내합니다 |
| 주소처럼 보이는데 읽지 못했다 | 주소를 그대로 복사해 다시 보내 달라고 안내하고, 읽은 링크의 결과는 함께 보냅니다 |
| 관련 없는 말을 보냈다 | 따로 가리지 않고 분석합니다. 사칭이나 요구가 없으면 찾지 못했다고 답합니다 |
