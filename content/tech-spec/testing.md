## 코드 테스트

| 수준 | 무엇을 확인하나 | 방식 |
| --- | --- | --- |
| 유닛 (`ai/tests/`) | 링크 추출, 근거 검증, 결론 관문, 사례 검색 | 가짜 LLM 클라이언트, 네트워크 없음 |
| 통합 (`tests/`) | 스킬 흐름, 결과 확인, 보안, 공식 대조 | FastAPI 테스트 클라이언트, AI와 수집기는 스텁 |
| 계약 | JSON 스키마와 pydantic 모델이 같은지 | 어긋나면 실패 |
| 배포 검증 | 격리 컨테이너의 방화벽과 브라우저 | 배포 뒤 EC2에서 `verify.py` |
| 실기기 | 카드 렌더링, 버튼, 글자 잘림 | 카카오 개발 채널에서 수동 |

## AI 응답 품질 점검

| 점검 | 방법 | 상태 |
| --- | --- | --- |
| 근거 충실성 | 인용이 원문에 있는지 코드가 검사 | 자동 |
| 금지 출력 | 안전 보증 표현이 없는지 금지어 검사 | 자동 |
| 폴백 | LLM 실패, 거부, 시간 초과에도 같은 모양의 결과 | 자동 |
| 결론 재현성 | 같은 입력이면 같은 결론 (순수 함수) | 자동 |
| 사례 검색 품질 | dev, test 분할로 hit@3, 정상 부착률 | 수동 |

**최근 측정**

- 링크 추출: 문자 12건을 2번씩, 24회 모두 기대와 같았고 중앙값 1.7초였습니다.
- 통화 결론 대리 평가: 실제 정상 통화 4,500건 중 의심 결론 5건(0.1%). LLM 대신 어휘표로 읽은 값이라 운영 수치가 아닙니다.

**비어 있는 곳**: CI에서 테스트 실행, 실제 모델 응답으로 재는 인젝션 평가, 사용자 테스트.
