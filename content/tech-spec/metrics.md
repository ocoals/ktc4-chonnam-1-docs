# 5. 추가 지표

AI 품질을 재기 위해 모을 값입니다. 문자 원문, URL, 사용자 ID는 남기지 않고 카드 이름, 코드, 개수, 소요 시간만 남깁니다.

| 지표 | 정의 | 지금 |
| --- | --- | --- |
| 결과 카드 분포 | 카드별 건수 ÷ 전체 결과 | 부분 |
| 판단 보류율 | "판단하기 어려워요" ÷ 링크 결과 | 추가 필요 |
| 오탐률 | 정상인데 의심 결론 ÷ 정상 | 평가셋만 |
| 누락률 | 사기인데 안전 쪽 결론 ÷ 사기 | 평가셋만 |
| LLM 폴백률 | 폴백 ÷ LLM 호출 (단계별, 실패 원인별) | 수집 |
| 신호 채택률 | 검증을 통과한 신호 ÷ LLM이 제안한 신호 | 추가 필요 |
| 단계별 지연 p50, p95 | 읽기, 수집, 페이지 검사, STT | 수집 |
| 콜백 실패율 | 콜백 실패 ÷ 콜백 시도 | 수집 |
| `자세히 보기` 클릭률 | 클릭 ÷ 결과 카드 | 추가 필요 |

**원칙**

- 지표마다 분자, 분모와 버전(코드 커밋, 프롬프트, 모델)을 함께 적습니다.
- 합성 데이터의 결과를 실제 탐지 성능으로 쓰지 않습니다. 운영 라벨은 KISA 결과 회수 같은 별도 경로가 필요합니다.

전체 지표는 [원문 5장](#spec-detail/5-추가-지표)에 있습니다.
