# 5. 추가 지표

AI 품질을 재기 위해 모을 값입니다. 문자 원문, URL, 사용자 ID는 남기지 않고 카드 이름, 코드, 개수, 소요 시간만 남깁니다.

| 지표 | 정의 | 무엇을 보나 |
| --- | --- | --- |
| **결과 분포** | | |
| 결과 카드 분포 | 카드별 건수 ÷ 전체 결과 | 결론이 한쪽으로 쏠리지 않는지 |
| 판단 보류율 | "판단하기 어려워요" ÷ 링크 결과 | 공식 도메인 목록과 수집이 충분한지 |
| **판정 품질** | | |
| 오탐률 | 정상인데 의심 결론 ÷ 정상 | 정상 문자를 의심하지 않는지 |
| 누락률 | 사기인데 안전 쪽 결론 ÷ 사기 | 사기 문자를 놓치지 않는지 |
| 과잉 보류율 | 공식 링크인데 판단 보류 ÷ 공식 링크 | 공식 주소를 지나치게 보류하지 않는지 |
| **LLM 단계** | | |
| LLM 폴백률 | 폴백 ÷ LLM 호출 (단계별, 실패 원인별) | 모델과 시간 상한이 맞는지 |
| 신호 채택률 | 검증을 통과한 신호 ÷ LLM이 제안한 신호 | LLM이 근거 없는 신호를 얼마나 내는지 |
| 링크 추출 누락률 | 기대한 링크 중 못 뽑은 비율 | 바꿔 적은 주소를 놓치지 않는지 |
| **안정성** | | |
| 45초 초과율 | 시간 초과 작업 ÷ 전체 작업 | 시간 상한이 충분한지 |
| 콜백 실패율 | 콜백 실패 ÷ 콜백 시도 | 결과가 사용자에게 닿는지 |
| 공식 판정 보류 사유 | 보류로 내린 사유별 건수 | 화이트리스트에 더할 후보 |
| **사용자 반응** | | |
| `자세히 보기` 클릭률 | 클릭 ÷ 결과 카드 | 근거를 궁금해하는지 |
| 「결과 확인」 사용률 | 결과 확인 요청 ÷ 작업 | 콜백을 기다리지 못하는지 |
| 질문 답 분포 | "이미 하신 게 있나요?"의 답별 건수 | 피해 뒤에 찾아오는 비율 |

**원칙**

- 지표마다 분자, 분모와 버전(코드, 프롬프트, 모델)을 함께 적습니다.
- 합성 데이터의 결과를 실제 탐지 성능으로 쓰지 않습니다. 실제 라벨은 KISA 확인 결과를 돌려받는 것 같은 별도 경로로 모읍니다.
