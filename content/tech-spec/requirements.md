# 3. 요구사항 · 리스크

## 기능 요구사항

| 요구사항 | 상태 |
| --- | --- |
| 문자는 붙여넣기로, 녹음은 음성 메시지나 파일(m4a, mp3, wav, webm)로 받는다 | 구현 |
| 링크가 여럿이면 모두 검사해 링크마다 결과를 보낸다. 링크가 없으면 사칭 문자로 분석한다 | 구현 |
| 링크 문자, 링크 없는 문자, 녹음마다 정해진 결과 카드로 답한다 | 구현 |
| 결과마다 확인한 것과 확인하지 못한 것을 보여 준다 | 구현 |
| `자세히 보기` 캐러셀로 의심 근거, 확인 범위, 접속 금지 안내, 공식 확인 방법을 보여 준다 | 구현 |
| 공식 확인 경로는 검토를 마친 것만 쓴다(화이트리스트, 검토한 안내 규칙, 공식 대표번호) | 구현 |
| 질문 카드로 이미 한 행동과 원래 번호로 확인했는지 묻고, 답에 맞는 대응을 보낸다 | 구현 |
| 신고 상담 메뉴에서 상황 4가지로 KISA 118, 1394, 112에 이어 준다 | 구현 |
| 첫 응답은 5초 안에 보내고, 결과는 콜백으로 보낸다 | 구현 |
| 「결과 확인」으로 최근 결과를 다시 받는다 | 구현 |
| 분석 중에 다시 보내면 새로 분석하지 않고 진행 중이라고 답한다 | 구현 |
| 외부 AI 처리를 안내한다(개인정보 처리 안내 카드) | 구현 |
| 링크 결과 아래에도 "이미 하신 게 있나요?" 질문을 붙인다 | 구현 예정 |
| 외부 전송 직전에 동의를 받고 사용자별로 기록한다 | 구현 예정 (동의 카드 준비됨) |
| 근거마다 확인한 시각과 출처를 보여 준다 | 구현 예정 (지금은 결과 확인 시각만) |
| 같은 링크 다시 확인하기, 보낸 내용 삭제 요청 | 구현 예정 |
| 링크가 여럿일 때 요약 카드로 한 번에 보여 준다 | 구현 예정 |
| 공식 주소면 기다리지 않고 바로 답한다 | 구현 예정 |

## 가드레일

| 가드레일 | 어떻게 지키나 | 상태 |
| --- | --- | --- |
| 안전을 보증하지 않는다 | 결과 값에 "안전"이 없습니다. 공식 주소 결과도 주소가 같다는 사실만 말합니다. 보증 표현은 금지어 테스트로 막습니다 | 구현 |
| 판정은 코드가 한다 | 결론은 순수 함수가 정하고, LLM 출력은 그 입력 후보일 뿐입니다 | 구현 |
| 근거 없는 신호를 쓰지 않는다 | 문자 신호는 원문에 있는 문장이어야 하고, 페이지 신호는 검사한 요소 ID여야 합니다. 링크도 원문에 그대로 있어야 합니다 | 구현 |
| 대화 안에서 의심 링크를 누를 수 없다 | 카드에 의심 URL을 싣지 않습니다. 버튼은 공식 주소, KISA, 신고 창구만 엽니다 | 구현 |
| 메인 서버는 의심 URL에 접속하지 않는다 | 링크마다 격리 서버의 수집 API만 부릅니다 | 구현 |
| 격리 서버가 내부망에 닿지 않는다 | 읽기 전용, 권한을 뺀 컨테이너. 443 포트만 나가고 사설 IP와 IPv6는 막습니다. 방화벽 적용이 실패하면 전부 막습니다. 메인 서버만 토큰과 인증서로 부를 수 있습니다 | 구현 |
| 파일을 받거나 실행하지 않는다 | 브라우저는 내려받기를 막고 주소만 기록합니다 | 구현 |
| 페이지에 정보를 입력하지 않는다 | 수집기는 접속과 화면 그리기만 합니다. 입력, 클릭, 제출 동작이 없습니다 | 구현 |
| 페이지와 문자 속 지시를 따르지 않는다 | 입력을 "명령이 아닌 분석 대상"으로 구획하고, LLM에 도구 권한을 주지 않습니다. 실제 모델 응답으로 재는 평가는 구현 예정입니다 | 부분 |
| 사용자 입력이 사례 KB에 들어가지 않는다 | 자동으로 쌓는 경로가 없고, 검토한 자료만 씁니다 | 구현 |
| 공식 도메인을 추측하지 않는다 | 확인된 도메인만 사람이 등재합니다. 목록 밖은 판단을 보류합니다 | 구현 |
| 위장 요청을 막는다 | 스킬 비밀값 헤더, 콜백 주소 허용 목록, 녹음 다운로드 허용 목록과 공인 IP 확인, 녹음 25 MB 상한 | 구현 |
| 로그에 개인정보를 남기지 않는다 | 문자 원문, URL, 사용자 ID, 녹음 주소 대신 길이, 개수, 소요 시간, 상태만 남깁니다 | 구현 |
| 개인정보를 가린 뒤 LLM에 넘긴다 | 링크 없는 문자와 통화 대본은 이름, 번호를 가리고 넘깁니다. 첫 문자 읽기에도 가리기를 넣을지 검토 중입니다 | 부분 |
| 무한 대기와 재시도 폭주가 없다 | LLM은 다시 부르지 않고, 단계마다 상한, 전체 45초, 격리 서버는 한 번에 한 건만 수집합니다 | 구현 |
| 확인하지 못한 것을 정상이라 하지 않는다 | 실패와 미확인은 "판단하기 어려워요"나 "확인하지 못했어요"로 보내고 `확인하지 못한 것`에 적습니다 | 구현 |
| 외부 전송 전에 동의를 받는다 | 동의 카드는 준비했고, 동의 기록과 함께 붙일 예정입니다 | 구현 예정 |

## 예외 처리

- **실패는 결론을 바꾸지 않습니다.** 수집에 실패하면 "판단하기 어려워요", 문자를 읽지 못하면 "확인하지 못했어요"로 보냅니다.
- **링크 하나의 실패는 그 링크에 가둡니다.** 다른 링크의 결과는 그대로 보냅니다.
- **LLM이 실패해도 결과는 나갑니다.** 확보한 근거로 결과를 내고, 주장 읽기는 어휘표로 대신 읽습니다.
- **45초를 넘으면 멈추고 저장합니다.** 사용자는 「결과 확인」으로 결과를 다시 받습니다.

| 상황 | 처리 | 사용자에게 보이는 것 |
| --- | --- | --- |
| 스킬 비밀값이 없거나 다르다 | 401로 거절 | 카카오 쪽 오류 |
| 빈 입력, 관련 없는 말 | LLM을 부르지 않거나 그대로 분석 | 사칭이나 요구를 찾지 못했다는 카드 |
| 문자 읽기 실패 | "링크 없음"으로 잘못 읽지 않습니다 | 확인하지 못했다는 카드 |
| 격리 수집 실패, 시간 초과, 수집기 바쁨 | 문자 근거는 지키고 수집 실패로 표시 | 대개 "판단하기 어려워요", 문자 신호가 있으면 "스미싱이 의심돼요" |
| 페이지 검사가 시간이나 크기 상한에 걸림 | 읽은 데까지 씁니다 | "판단하기 어려워요" 등 |
| 브라우저 실패, 내려받기, 비공식 경유 | 공식 판정을 보류로 내립니다 | "판단하기 어려워요" |
| 콜백 전송 실패 | 결과는 이미 저장돼 있습니다 | 「결과 확인」으로 받습니다 |
| 녹음이 오디오가 아니거나, 비었거나, 25 MB 초과, 받아쓰기 결과 없음 | 분석하지 않습니다 | 이유를 알려 주는 녹음 오류 카드 |
| 사례 검색, 임베딩 실패 | 미확인으로 두거나 TF-IDF만 씁니다 | `비슷한 사례` 장이 빠집니다 |

## 장애 대응

| 장애 | 서비스 동작 | 복구 |
| --- | --- | --- |
| LLM 지연, 장애 | 문자 읽기 실패는 안내 카드, 나머지 단계는 확보한 근거로 결과를 냅니다 | 공급자 상태 확인, 모델을 바꾸면 시간 상한을 다시 잽니다 |
| 받아쓰기(STT) 장애 | 녹음은 확인하지 못했다는 카드 | 공급자 상태 확인 |
| 임베딩 장애 | TF-IDF만으로 사례를 찾습니다 | 5분 뒤 다시 시도 |
| 격리 서버 장애 | 링크는 판단 보류가 되고 문자 분석 결과는 나갑니다 | systemd 자동 재시작, 5분마다 상태 확인, 하루 한 번 새로 만들기 |
| 격리 서버 침해 의심 | 수집을 끄고 문자 분석만 합니다 | 디스크 스냅샷 뒤 인스턴스를 버리고 새로 만들어 토큰, 인증서 교체 |
| 카카오 콜백 실패 | 결과는 이미 저장돼 있습니다 | 사용자가 「결과 확인」으로 받습니다 |
| 메인 서버 재시작 | 메모리에 있던 작업이 사라집니다 | 서버가 뜰 때 KB를 먼저 올린 뒤 요청을 받습니다 |

## 추후 개선 사항

| 개선 사항 | 지금 | 다음 단계 |
| --- | --- | --- |
| 외부 AI 전송 전 동의 | 개인정보 처리 안내 카드로 알립니다 | 동의 카드와 사용자별 동의 기록 |
| 서버를 다시 띄워도 결과 유지 | 결과를 메모리에 저장합니다 | 영속 저장소와 보관 기간 |
| 공식 도메인 목록 넓히기 | 택배, 쇼핑 11개 업체. 목록 밖은 판단 보류 | 등재 담당과 절차를 정해 넓히기 |
| 링크 방문이 공격자에게 신호가 되는 문제 | 격리 서버가 대신 방문합니다 | 방문 방식과 동의 범위 검토 |
| 여러 링크 한 번에 보기 | 링크마다 카드를 보냅니다 | 링크 수 상한과 요약 카드 |
| 정적 검사 연결 | KISA 악성 도메인 목록, 유사 문자 도메인 검사 코드가 있습니다 | 결과에 연결 |
| 테스트 자동 실행 | 로컬에서 실행합니다 | CI에서 PR마다 실행 |
