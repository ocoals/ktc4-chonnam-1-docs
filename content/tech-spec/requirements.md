## 핵심 가드레일

| 가드레일 | 어떻게 지키나 | 상태 |
| --- | --- | --- |
| 안전을 보증하지 않는다 | 결과에 "안전" 값이 없습니다. 보증 표현은 금지어 테스트로 막습니다 | 구현 |
| 판정은 코드가 한다 | 결론은 순수 함수가 정하고, LLM 출력은 그 입력 후보일 뿐입니다 | 구현 |
| 근거 없는 신호를 쓰지 않는다 | 인용이 원문에 있어야 하고, 페이지 신호는 검사한 요소 ID여야 합니다 | 구현 |
| 의심 링크를 누를 수 없다 | 카드에 의심 URL을 싣지 않습니다. 버튼은 공식 주소와 신고 창구만 엽니다 | 구현 |
| 의심 URL은 격리 서버만 연다 | 컨테이너 제한, 443 외 차단, 사설 IP 차단, 토큰과 인증서 | 구현 |
| 페이지 속 지시를 따르지 않는다 | 입력을 데이터로 구획하고, LLM에 도구 권한을 주지 않습니다 | 부분 |
| 외부 전송 전에 동의를 받는다 | 고지 카드만 있고 동의 기록은 없습니다 | 미구현 |

## 예외 처리 원칙

- **실패는 결론을 바꾸지 않습니다.** 수집에 실패하면 "판단하기 어려워요", 문자를 읽지 못하면 "확인하지 못했어요"로 보냅니다.
- **링크 하나의 실패는 그 링크에 가둡니다.** 다른 링크의 결과는 그대로 보냅니다.
- **45초를 넘으면 멈추고 저장합니다.** 사용자는 「결과 확인」으로 결과를 다시 받습니다.

## 장애 대응

| 장애 | 서비스 동작 | 복구 |
| --- | --- | --- |
| LLM 지연, 장애 | 문자 읽기 실패는 안내 카드, 나머지 단계는 확보한 근거로 결과를 냅니다 | 공급자 확인, 시간 상한 재측정 |
| 격리 서버 장애 | 링크는 판단 보류가 되고 문자 분석 결과는 나갑니다 | systemd 자동 재시작, 하루 한 번 재생성 |
| 카카오 콜백 실패 | 결과는 이미 저장돼 있습니다 | 사용자가 「결과 확인」으로 받습니다 |
| 메인 서버 재시작 | 메모리에 있던 작업이 사라집니다 | 영속 저장소는 남은 일입니다 |

## 남은 리스크

| 리스크 | 지금 대응 |
| --- | --- |
| 동의 없이 문자 원문과 녹음이 외부 AI API로 나간다 | 개인정보 처리 안내 카드로 고지. 동의 방식은 열린 결정입니다 |
| 서버를 다시 띄우면 작업이 사라진다 | 안내 문구. 영속 저장소가 필요합니다 |
| 공식 도메인 목록이 좁다 (11개 브랜드) | 목록 밖은 추측하지 않고 판단 보류로 보냅니다 |
| 링크 방문 자체가 공격자에게 신호가 된다 | 감수하고 검토 중입니다 |

전체 요구사항(FR), 가드레일(GR), 예외(EX), 장애(OP), 리스크(RS) 표는 [원문 3장](#spec-detail/3-요구사항-리스크)에 있습니다.
