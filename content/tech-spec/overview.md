# 테크스펙

**화기니**는 의심 문자와 통화 녹음을 카카오톡으로 받아, 근거와 함께 확인 결과를 알려 주는 챗봇입니다.
위험하면 KISA, 1394, 112 상담으로 이어 줍니다.

<div class="stats">
  <div><strong>3가지</strong><span>링크 있는 문자, 링크 없는 사칭 문자, 통화 녹음</span></div>
  <div><strong>5초</strong><span>카카오 첫 응답 상한. 결과는 콜백으로</span></div>
  <div><strong>45초</strong><span>분석 전체 상한</span></div>
  <div><strong>1,442개</strong><span>테스트 함수</span></div>
</div>

## 세 가지 원칙

1. **판정은 코드가 합니다.** 공식 도메인 대조와 정해진 규칙이 결론을 냅니다. LLM에게 "위험한가"를 묻지 않습니다.
2. **LLM은 읽기만 합니다.** 문자를 읽고, 근거가 있는 신호를 제안합니다. 근거가 실제 입력에 있는지 코드가 확인한 것만 씁니다.
3. **의심 링크에는 격리 서버만 접속합니다.** 메인 서버와 사용자 기기는 의심 링크에 닿지 않습니다.
