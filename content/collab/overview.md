# 개요와 팀 소개

## 화기니는

택배 사칭 스미싱, 가족이나 기관을 사칭하는 문자, 보이스피싱 통화 녹음을 카카오톡으로 받아 **근거와 함께** 확인 결과를 알려 주는 챗봇입니다.
위험하면 KISA, 1394, 112 상담으로 이어 줍니다.

판정은 공식 도메인 대조 같은 결정적 코드가 하고, LLM은 문자를 읽고 근거가 있는 신호를 제안하는 일만 합니다.
자세한 설계는 [테크스펙](/tech-spec/)에 있습니다.

## 팀 소개

카카오테크캠퍼스 4기 전남대 1팀입니다. 모든 팀원은 **팀 역할** 하나와 **프로젝트 역할**(FE, BE, AI 엔지니어)을 함께 맡았습니다.

### 팀 역할

| 팀 역할 | 하는 일 |
| --- | --- |
| 팀장 (PM) | 일정과 방향을 총괄하고 작업을 나눕니다. `develop` → `main` 멘토 리뷰 PR을 맡습니다 |
| FE, BE, AI 리드 | 파트의 기술 결정을 이끌고, 파트 PR 리뷰를 주도합니다 |
| 플래너 | 팀 일정과 마감, 멘토링, 특강 일정을 챙기고 알립니다 |
| 메이커 | 회의 내용과 의사결정의 맥락을 기록합니다 |
| 팀원 공통 | 작업 상황을 공유하고, `develop` 에 올라온 PR을 함께 리뷰합니다 |

## 우리가 일한 방식

한 스프린트에 주제 하나를 정하고, 파트별 브랜치에서 만든 뒤 주제 브랜치로 모아 맞춰 보았습니다. 화요일, 목요일 대면 회의로 진행 상황을 맞췄습니다.
스프린트가 끝날 때마다 `develop` → `main` PR로 멘토 리뷰를 받고, 받은 피드백은 `refactor` 브랜치에서 고쳐 다음 스프린트에 이어 갔습니다.
